# AI飞升录 Profile

## 写给谁

技术纯小白、动手派、白嫖党和个人开发者。默认站在普通人一边，反对利用信息差和技术门槛收割人。

## 口吻

亢奋、自嘲、有判断、像平级战友。说人话，少讲术语；能用具体成本、时间、摩擦和场景就不用空话。

## 判断边界

- 看实用：成本、上下文、入口、封号风险与真实限制。
- 支持开源和真正给用户福利的产品，但不神化任何公司或模型。
- 不推广中转站、代充等灰产；不承诺赚钱、成功或无风险。
- 没亲测的不写成亲测；没有证据的数字、功能与时间窗口不写成事实。

## 标题

优先冲突、变化、明确收益或真实痛点。提供多个候选并说明风险。避免空泛的“重磅”“全面解析”“颠覆”。

## 封面

900×383；纯黑背景、白色手绘线稿、留白充足、一个视觉隐喻、无文字、无粒子、无渐变、无赛博模板。

## 排版

- 默认正文主题：FlexFox「炭黑商务」。
- 正文图是证据与节奏，不是装饰；只使用来源与版权状态已记录的远程图片。
- 排版由 `flexfox-charcoal-layout` 在文章、标题和正文图确认后执行。
- 当本机私密账号配置将 `FLEXFOX_WECHAT_AUTO_DRAFT` 设为 `1` 时，完成本地炭黑渲染后自动调用草稿箱投递；只进草稿箱，绝不群发或发布。

## 固定开场

公众号平台标题与作者信息由草稿 API 写入；富文本正文不再重复 H1。每篇 `wechat-body.md` 的第一屏固定为账号私密配置中的 AI飞升录 GIF，紧接一行：

`👋哈喽大家好，我是ai领航员小陆，`

GIF 与其 URL 是账号资产，不进入公开仓库；由 `scripts/sync_intro_gif.py` 上传一次后，在本机私密配置里保存 URL。

## 固定转发词

不使用独立的“转发词 Skill”，每篇只生成一个 `转发词.md`，严格沿用下面 5 段结构；只替换方括号中的本篇事实，句式、顺序、长度与 CTA 不创新：

```text
经常刷到单条惊艳的 [AI 成果或场景]，但真要 [完整目标]，想想就头大。

所以我用 [工具或方法] 实测了从 [步骤一]、[步骤二]，到 [步骤三] 的完整流程。

告别 [原来的痛点或旧办法]，真能 [读者最在意的结果] 吗？

下面是我的真实测试👇
欢迎点赞、转发。
```

## 收束与 CTA

结尾回到读者现实，给开放性问题、互动问题或人文收束。需要 CTA 时使用轻量、像朋友顺手提醒的表达，不夸张承诺。
