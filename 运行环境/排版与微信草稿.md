# 排版与微信草稿：当前运行说明

生产规则以根目录 AGENTS.md 和 references/pipeline-contract.md 为准。新文章唯一母本 article.md，图片 images/，其余产物在 过程/。历史文章.md 不自动转换。

运行入口优先使用 FLEXFOX_PYTHON 指定的解释器或 .venv/bin/python3，未配置时查找系统 python3。要求 Python 3.10+；包校验另需 PyYAML，可用 uv 按需安装。

```sh
sh 运行环境/wechat.sh preview --article-dir "文章/YYYY-MM-DD-主题"
sh 运行环境/wechat.sh check --article-dir "文章/YYYY-MM-DD-主题"
sh 运行环境/wechat.sh diagnose --article-dir "文章/YYYY-MM-DD-主题"
```

preview 要求 preflight 通过，按当前 Profile 注入开场 GIF 和问候语，生成 过程/wechat-body.md 与本地预览。GIF 缺失时停止；须先配置真实素材，不允许填占位 URL。

config/wechat.local.env 保存本机密钥，应设置为仅本人可读写，并由 .gitignore 排除。凭据验证只证明当次账号与出口可用，不代表草稿创建验收。

仅在用户明确授权当前文章入草稿箱后执行：

```sh
sh 运行环境/wechat.sh validate
sh 运行环境/wechat.sh draft --article-dir "文章/YYYY-MM-DD-主题" --title "最终标题" --confirm-draft
```

直接调用 wechat_draft.py 同样强制检查 preflight、终审正文与投递正文一致性、开场 GIF、图片、摘要和既有回执。创建草稿前落盘 attempt 记录；超时或回读失败时必须先核对草稿箱，禁止盲目重试。工具不发布、不群发、不删除草稿。

已有草稿需更新时，不可把回执删除后再次运行 draft。当前通用 CLI 尚不提供 update；对旧草稿的定向更新须核对目标并在更新后比较全文，不能只凭返回成功就宣称新版已同步。
