# 炭黑商务：渲染合同

基准：2026-09-27 对「炭黑商务」样式作了参数核对。FlexFox 将这些已确认参数固化为自己的本地渲染合同，不依赖 Flowcast 页面、剪贴板或其运行时。

本文件规定本地渲染器的唯一视觉来源。最终富文本由 `scripts/render_charcoal.py` 直接产生，再交给公众号草稿接口。

## 主题识别

- 风格名称：`炭黑商务`
- 渲染键：`charcoal`
- 导出根节点：`data-ff-theme="charcoal"`
- 外层左右内边距：`0 8px`
- 正文字体：`sans-serif`
- 正文字色：`#27272A`
- 正文字号：`16px`
- 正文行高：`2.1`
- 段落：`margin: 0 0 28px 0`

微信客户端会按系统字库解析 `sans-serif`，所以无法也不应伪造某一台设备上的单一字体文件；其余数值由 FlexFox 的内联样式写入。

## 标题层级

| 元素 | 数值 |
|---|---|
| H1 | `34px`、`900`、`#09090B`、左对齐、字距 `-1.5px`、下间距 `40px` |
| H2 | 上/下间距 `32px / 24px`、`24px`、`800`、白字、背景 `#18181B`、内边距 `10px 20px`、圆角 `4px` |
| H3 | 上/下间距 `24px / 24px`、`20px`、`700`、`#3F3F46` |
| 加粗 | `900`、`#000` |

文章生成规则：正文一级小标题使用 `##`，场景内的小标题使用 `###`。不为视觉而堆叠标题层级。

## 正文图片

- 只允许完整 `https://` URL 与准确 alt 文本；不得使用本机路径、data URI、base64、营销海报、无来源图片或未核验版权图片。
- 单张图片：`display: block`、居中、圆角 `16px`、下间距 `28px`，图片维持原比例且不拉伸。
- 一张图单独成行，上下保留空行；本地渲染器按顺序堆叠相邻图片。只有文章叙事确实需要连续对照时才使用图片组布局。
- 封面是 `images/cover-900x383.png`，默认不插入正文。

## 其他现成元素

- 引用：上/下 `24px`；内边距 `20px 24px`；左边框 `8px solid #18181B`；背景 `#F4F4F5`；右侧圆角 `12px`。
- 代码块：上/下 `32px`；背景 `#09090B`；圆角 `12px`；代码 `14px`。
- 分隔线：`2px solid #18181B`，上/下 `48px`。默认文章不使用分隔线。

## 不可承诺项

本地渲染器保证每次送入微信的是同一份内联富文本；公众号网页编辑器和读者设备仍可能由微信统一处理字体回退、深色模式、超宽图片压缩或未来的 HTML 清洗规则。因此“像素级、所有设备绝无差别”不是任何 Skill 可以诚实承诺的结果。

可承诺的验收边界是：按本合同生成内联 HTML，并在公众号编辑器内人工核对一次标题、正文、单图和引用块。若微信改写某一项，记录为微信兼容层差异，再针对该项修正；不猜测。
