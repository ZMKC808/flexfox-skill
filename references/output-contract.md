# 交付合同

完整写稿只交付下列可复用资产；没有完成的项明确标注原因，不伪造通过状态。

| 文件 | 必须性 | 内容 |
|---|---|---|
| `brief.md` | 必须 | 读者、主线、情绪、不聊什么、确认依据 |
| `evidence.md` | 必须 | 来源、已核验事实、推断、待核验项 |
| `title-options.md` | 必须 | 至少 5 个标题、风险、最终标题 |
| `digest.md` | 必须 | 1–2 句、15–20 字且不超过 25 字的钩子摘要 |
| `article.md` | 必须 | 唯一正文源 |
| `review.md` | 必须 | AI 味、事实、结构与修订结果 |
| `转发词.md` | 完整写稿必需 | 账号固定句式，只替换与本篇相关的关键词 |
| `wechat-body.md` | Profile 指定或用户要求排版时必需 | 固定开场后的公众号正文输入稿，只含远程正文图 |
| `layout-checklist.md` | Profile 指定或用户要求排版时必需 | 炭黑商务样式与草稿预览验收记录 |
| `wechat-draft.json` | 已获授权推入草稿箱时必需 | 不含密钥或正文的草稿回执与核验状态 |
| `images/cover-900x383.png` | 有生图能力时必需 | 最终封面，900×383 |
| `images/cover-prompt.md` | 无生图能力时必需 | 可复用封面提示词 |
| `images/manifest.md` | 有正文图时必需 | 每张图的用途、来源与版权状态 |
| `adaptation.md` | 二创任务必需 | 来源、独立角度、复用边界与署名方案 |

`article.md` 仍是唯一正文源。炭黑排版器只读取它并产生临时内联富文本；不把 HTML 或 base64 图片写回项目。

禁止创建 `发布版.md`、保存渲染后的 HTML、在正文中使用本地图片路径或 base64 图片、使用未经版权核验的图床 URL。草稿箱投递只可由 `flexfox-wechat-draft` 在明确授权下完成；群发与自动发布不属于本系统。
